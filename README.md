# Nur Divle Portföy

Bu klasör GitHub ve Vercel için hazırlanmış portföy sürümüdür.

GitHub'a bu klasörün içindekileri yükle. Vercel projesinde `NEXT_PUBLIC_SUPABASE_URL` ve `NEXT_PUBLIC_SUPABASE_ANON_KEY` ortam değişkenlerini eski projendeki değerlerle ekle; böylece `/yonetim` sayfasındaki kayıt işlemi çalışır.
